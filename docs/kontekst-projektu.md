# Kontekst Projektu - Sklep Internetowy

## Wizja systemu
Stworzenie nowoczesnej, responsywnej platformy e-commerce umożliwiającej użytkownikom przeglądanie asortymentu, dodawanie produktów do koszyka, bezpieczne płacenie online oraz śledzenie statusu zamówienia. System ma zapewniać administratorom proste narzędzia do zarządzania produktami i zamówieniami, a klientom intuicyjny proces zakupowy.

## Lista aktorów
1. **Gość** - niezalogowany użytkownik. Może przeglądać produkty i dodawać je do koszyka. Przed złożeniem zamówienia musi się zarejestrować lub zalogować.
2. **Klient** - zalogowany użytkownik. Może kupować, zarządzać swoim profilem, przeglądać historię zamówień i dodawać opinie.
3. **Administrator** - pracownik sklepu. Zarządza produktami, kategoriami, zamówieniami i kontami użytkowników.
4. **System Płatności (zewnętrzny)** - bramka płatnicza (np. Przelewy24, PayU) integrowana z systemem w celu autoryzacji transakcji.
